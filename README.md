# 🌙 MoonUI

Eine moderne, anpassbare Windows-Desktop-Overlay-Anwendung im **Dynamic-Island-Style** (entwickelt mit **WPF / .NET 10**), ausgestattet mit integrierter Schnellsuche, App-Launcher, praktischem Shelf (Ablage) und Live-Widgets.

> *Hinweis: Ein Hybrid-Projekt, das in Teilen von Google Antigravity begleitet wurde. Entwickelt als Testprojekt, um meine Fähigkeiten in der Microsoft .NET 10 WPF-Architektur weiterzuentwickeln.*

---

## 🚀 Funktionsumfang

- **Modernes .NET 10 WPF Backend:** Schlanke, performante Architektur mit flüssigen Animationen.
- **Ressourcenschonend:** Extrem CPU- und RAM-sparend, ohne in die Windows 11 Kernintegrität einzugreifen.
- **Google-Kalender API Integration:** Direkte Termineinsicht und Live-Updates auf dem Desktop.
- **Integrierte Schnellsuche & Clipboard:** Schnelles Auffinden von Dateien und Verwalten der Zwischenablage.
- **Dynamic-Bar & Live-Widgets:** Flüssige UI-Zustandswechsel und interaktive Widgets.
