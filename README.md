# MoonUI
MoonUI – Eine moderne, anpassbare Windows-Desktop-Overlay-Anwendung im Dynamic-Island-Style (WPF / .NET 10), ausgestattet mit integrierter Schnellsuche, App-Launcher, praktischem Shelf (Ablage) und Live-Widgets.

Es handelt sich hierbei um ein Hybrid-Projekt was in teilen von Google Antigravity begleitet wurde.
Ein Testprojekt um meine Fähikeiten in der Microsoft .NET 10 WPF weiterzuentwicklen.
